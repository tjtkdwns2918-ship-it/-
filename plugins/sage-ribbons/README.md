# Sage Ribbons — Claude theme

Claude 데스크톱·모바일 앱용 세이지 그린 테마입니다. 연한 회녹색 바탕 위로 연두색에서 짙은 숲색까지 이어지는 종이 리본이 화면 모서리에서 천천히 흔들립니다. 라이트·다크 모드를 모두 지원하며, 메시지는 둥근 녹색 카드로 표시됩니다.

A soft sage-green look for the Claude desktop and mobile apps: pale gray-green surfaces, forest-green accents, and layered paper ribbons that sway slowly in from two corners. Works in both light and dark mode. The terminal draws no theme.

## 설치 / Install

```
/plugin install sage-ribbons --marketplace tjtkdwns2918-ship-it/claude-sage-theme
```
